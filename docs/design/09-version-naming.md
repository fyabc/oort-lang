# 天体命名版本号方案

> 整理自项目早期的设计讨论（原始记录未纳入仓库）。

---

## 1. 方案概述

Oort 语言的内部版本使用天文学中的星名（A-Z 字母对应），外部发布使用语义化版本号。

## 2. 内部版本命名

| 字母 | 星名 | 中文名 |
|------|------|--------|
| A | Altair | 牛郎星 |
| B | Betelgeuse | 参宿四 |
| C | Canopus | 老人星 |
| D | Deneb | 天津四 |
| E | Epsilon Eridani | 天苑四 |
| F | Fomalhaut | 北落师门 |
| G | Gacrux | 南河二 |
| H | Hadar | 马腹一 |
| ... | ... | ... |

## 3. 双轨版本制

- **内部**：天体名版本（开发阶段标识）
- **外部**：语义化版本 SemVer（用户可见）

示例：`v0.1.0 "Altair"` → `v0.2.0 "Betelgeuse"`

## 4. 注意事项

- 天体名仅作内部开发标识，不对外宣传
- 正式发布始终使用语义化版本号
- 部分 IAU 星名可能随时间变化，需核实
