# 表达式

## 原子表达式

```text
字面量
identifier
this
super
super(args...)
(a, b)              # 元组字面量
[1, 2, 3]           # 列表
{: ... :} {. ... .}
a.b                 # 属性访问
a[b]                # 下标
a[1:3]、a[::2]      # 切片
f(args)             # 调用
f(args) do ...      # 尾随 lambda
{ statements }      # 块表达式
if ... / while ... / for ...
def ... / class ... / do ...
```

## 运算符

二元运算的求值顺序为从左到右（先求左操作数，再求右操作数）。
`and` / `or` 短路：返回决定结果的操作数本身，而不强制转换为布尔值。

```oort
1 and 2     # 2
0 or 3      # 3
```

真值规则与 Python 相同：`null`、`false`、数值 0、空字符串、空容器为假；
其余为真。

比较与运算对底层 Python 值执行，因此：

- 数值之间按数值比较；
- 字符串按字典序比较；
- 列表/元组按元素逐项比较；
- `is` / `!is` 比较对象身份；
- `in` / `!in` 对容器做成员测试（字典测试键，集合测试元素）。

> 运算符重载尚未接入调度：用户类无法通过 `operator "+"` 等方法改变运算行为；
> 对不支持的类型会抛出运行期错误。见 [conformance](06-conformance.md)。

## 下标与切片

```oort
[1, 2, 3][1]        # 2
[1, 2, 3][-1]       # 3
"abc"[1]            # "b"
{: "a": 1 :}["a"]   # 1
[0, 1, 2, 3][1:3]   # [2, 3]
[0, 1, 2, 3][::2]   # [0, 2]
"hello"[1:]         # "ello"
```

- 下标表达式可以带多个参数（会组成元组），为未来的多维下标保留。
- 切片对 List/Tuple/String 返回同类型的新对象。
- 越界/类型错误转换为 `OortRuntimeError`。

## 属性访问

- 实例属性先查实例字段，再沿类的 MRO 查类属性；函数会绑定为方法。
- 类对象的属性先查类 MRO（返回未绑定函数），再查元类 MRO（绑定为类方法）。
- 访问不存在的属性抛出 `OortAttributeError`。

## 调用

```oort
f(1, 2)
f do x: x + 1          # 唯一实参是 lambda，可省略括号
f(1) do x: x + 1       # lambda 作为最后一个实参
```

- 实参按位置绑定，实参数量必须与形参数量一致。
- 关键字实参（`f(x=1)`）语法可解析，但当前显式拒绝。
- `C(...)` 创建实例：先创建对象，再调用 `__init__`。

## 块与语句表达式

块 `{ ... }` 的值是最后一条语句的值；空块的值为 `null`。
`if`、`while`、`for` 也是表达式，默认值为 `null`（`if` 返回被选中分支的值）。

## 错误

表达式阶段可能产生：

| 异常 | 场景 |
|------|------|
| `OortNameError` | 名字未定义 |
| `OortAttributeError` | 属性不存在 |
| `OortTypeError` | 运算/调用类型不匹配、参数数量不符 |
| `OortRuntimeError` | 下标越界等其他运行期错误 |
