# 词法结构

## 源文件

- 编码：UTF-8（允许 UTF-8 BOM）。
- 扩展名：`.ort`。
- 行尾：`\n` 或 `\r\n` 均可。

## 方言声明

文件首行可以声明模块方言：

```oort
#lang oort-object
```

- 缺省方言为 `oort-object`；显式声明是可选的自文档化写法。
- 指令必须从第一行第 1 列开始（允许 UTF-8 BOM），方言名区分大小写。
- `#lang` 在词法上仍是一条注释，因此不改变行号与错误定位。
- `#lang` 出现在其他行时报语法错误，而不是被静默当作注释。
- 未知方言会被显式拒绝；已注册但尚未实现的方言也会被拒绝。
- 当前 `oort-object`（动态）与 `oort-core`（薄静态探针）均已实现；后者见
  [11-core-probe.md](11-core-probe.md)。
- 方言只选择语义分析与特性门控；词法与语法是各方言共享的超集。

## 空白与注释

- 空格与制表符被忽略。
- `#` 到行尾为注释。
- 语句以换行或 `;` 分隔。

### 换行规则

换行在以下情况被**忽略**（不产生 `NEWLINE` token）：

- 位于 `(` `)`、`[` `]`、`{: :}`、`{. .}` 内部，且最内层括号不是 `{` `}`；
- 行尾是反斜杠 `\`（显式续行）；
- 下一行以 `.` 开头（方法链续行）：token 后处理层会丢弃紧邻 `.` 的
  `NEWLINE`，例如：

  ```oort
  val name = user
      .profile()
      .name()
  ```

否则换行结束当前语句。代码块 `{ ... }` 内部的换行仍然分隔语句。

REPL 逐行判断输入是否完整，无法预知下一行是否以 `.` 开头，因此行首 `.`
续行只适用于文件或一次性提交的整段输入；交互输入请使用行尾 `\`。

## 标识符

- 首字符为 ASCII 字母、`_` 或非 ASCII 字母（含中文，但排除中文标点）。
- 后续字符可为字母、数字、`_`。
- `!` **不**属于标识符；`a!=b`、`x!in xs`、`a!is b` 无需空格即可正确分词。
- `$0`、`$1`、…… 是匿名 lambda 参数；只能在无显式参数列表的 lambda 中
  使用（[OP 0010](../proposals/0010-token-responsibilities-and-anonymous-parameters.md)）。

## 关键字

硬关键字：

```text
and or not in !in is !is as
var val do def class enum match this super
if else elif for while break continue return
macro import yield await
true false null
```

软关键字（可作为普通标识符）：`operator`、`infix`、`from`。

## 字面量

### 整数

```text
42      十进制
0d42    显式十进制
0b1010  二进制
0o17    八进制
0x1F    十六进制
```

### 浮点数

```text
1.5
2e3
1.5e-2
```

不支持 `1.`（避免与 `1.method` 混淆）；同样不支持 `.5`——小数点前后都
必须有数字，写作 `0.5`（[OP 0021](../proposals/0021-float-integer-part.md)）。

### 字符串

- 短字符串：`"..."`、`'...'`。
- 长字符串：`"""..."""`、`'''...'''`。
- 原始字符串前缀 `r` / `R`：不处理转义。
- 格式化字符串 `f"..."` **未实现**，会报 `UnsupportedSyntax`。

### 布尔与空值

`true`、`false`、`null`。

### 容器字面量

```oort
[1, 2, 3]              # List
(1, 2)                 # Tuple；单元素 (1,)
()                     # 空元组
{: "a": 1 :}           # Dict；空字典 {:}
{. 1, 2 .}             # Set；空集合 {.}
```

定界符助记：冒号的两点对应字典条目的成对结构（k-v），点号的一点对应
集合的单个元素。

字典的 `**expr` 展开语法可解析，但未实现（显式报错）。

## 运算符

用户自定义运算符由以下字符组成：

```text
! % & * + - / < = > ? ^ | ~
```

`.`、`:`、`@` **不属于**用户运算符字符，它们分别是成员访问、作用域/类型标注、
宏调用的结构字符。

内建运算符优先级（数值越大绑定越紧）：

| 优先级 | 运算符 | 结合性 |
|--------|--------|--------|
| 900 | `**` | 右 |
| 700 | `*` `/` `//` `%` | 左 |
| 600 | `+` `-` | 左 |
| 400 | `<<` `>>` | 左 |
| 340 | `&` | 左 |
| 330 | `^` | 左 |
| 320 | `\|` | 左 |
| 300 | `<` `<=` `>` `>=` `in` `!in` `is` `!is` `==` `!=` | 非结合 |
| 90 | `and` | 左 |
| 80 | `or` | 左 |

位运算绑定**高于**比较（`flags & 1 == 0` = `(flags & 1) == 0`）。
比较运算非结合：`0 <= i < n` 是语法错误，应写成 `0 <= i and i < n`。

前缀运算符：`+` `-` `~`（优先级 800）、`not`（优先级 100）、`await`（1000，未实现）。
未显式声明的用户运算符使用默认优先级：前缀 800，中缀 500，左结合。
隐式中缀调用当前关闭；`a b c` 会报错，等 OP 0002 的显式 `infix` 声明落地后再启用。
