# 词法结构

## 源文件

- 编码：UTF-8。
- 扩展名：`.ort`。
- 行尾：`\n` 或 `\r\n` 均可。

## 空白与注释

- 空格与制表符被忽略。
- `#` 到行尾为注释。
- 语句以换行或 `;` 分隔。

### 换行规则

换行在以下情况被**忽略**（不产生 `NEWLINE` token）：

- 位于 `(` `)`、`[` `]`、`{: :}`、`{. .}` 内部，且最内层括号不是 `{` `}`；
- 行尾是反斜杠 `\`（显式续行）。

否则换行结束当前语句。代码块 `{ ... }` 内部的换行仍然分隔语句。

## 标识符

- 首字符为 ASCII 字母、`_` 或非 ASCII 字母（含中文，但排除中文标点）。
- 后续字符可为字母、数字、`_`。
- 允许以 `!` 结尾（如 `empty!`）。
- `$0`、`$1`、…… 是匿名形参的保留形式；当前实现会显式拒绝。

## 关键字

硬关键字：

```text
and or not in !in is !is as
var val do def class this super
if else elif for while break continue return
macro import yield await
true false null
```

软关键字（可作为普通标识符）：`operator`、`infix`、`from`。

## 字面量

### 整数

```text
42      十进制
0d42    显式十进制
0b1010  二进制
0o17    八进制
0x1F    十六进制
```

### 浮点数

```text
1.5
2e3
1.5e-2
```

不支持 `1.`（避免与 `1.method` 混淆）。

### 字符串

- 短字符串：`"..."`、`'...'`。
- 长字符串：`"""..."""`、`'''...'''`。
- 原始字符串前缀 `r` / `R`：不处理转义。
- 格式化字符串 `f"..."` **未实现**，会报 `UnsupportedSyntax`。

### 布尔与空值

`true`、`false`、`null`。

### 容器字面量

```oort
[1, 2, 3]              # List
(1, 2)                 # Tuple；单元素 (1,)
()                     # 空元组
{: "a": 1 :}           # Dict；空字典 {:}
{. 1, 2 .}             # Set；空集合 {.}
```

字典的 `**expr` 展开语法可解析，但未实现（显式报错）。

## 运算符

用户自定义运算符由以下字符组成：

```text
! % & * + - / < = > ? ^ | ~
```

`.`、`:`、`@` **不属于**用户运算符字符，它们分别是成员访问、作用域/类型标注、
宏调用的结构字符。

内建运算符优先级（数值越大绑定越紧）：

| 优先级 | 运算符 | 结合性 |
|--------|--------|--------|
| 900 | `**` | 右 |
| 700 | `*` `/` `//` `%` | 左 |
| 600 | `+` `-` | 左 |
| 400 | `<<` `>>` | 左 |
| 300 | `<` `<=` `>` `>=` `in` `!in` `is` `!is` | 左 |
| 200 | `==` `!=` | 左 |
| 180 | `&` | 左 |
| 160 | `^` | 左 |
| 140 | `\|` | 左 |
| 90 | `and` | 左 |
| 80 | `or` | 左 |

前缀运算符：`+` `-` `~`（优先级 800）、`not`（优先级 100）、`await`（1000，未实现）。
未显式声明的用户运算符使用默认优先级：前缀 800，中缀 500，左结合。
